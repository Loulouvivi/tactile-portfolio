# Contemporary Grotesk Typography Test

## Goal
Test a distinctive modern grotesk/geometric sans-serif across the existing portfolio while preserving every layout, paper, image, colour, spacing, and content decision.

## Changes
- Replace the current Instrument Serif display face with Space Grotesk, using its broad proportions and crisp geometric construction for a contemporary editorial feel.
- Apply it through the existing display typography token so the hero headline, section headings, project titles, and Studio Marlow wordmark update without restructuring markup.
- Apply the same family to navigation while retaining the existing uppercase scale and spacing.
- Keep Work Sans for restrained body copy and small uppercase metadata.
- Preserve Instrument Serif only for the expressive italic emphasis on “feel” and “solid”; keep the existing mauve accent and use the italic as a deliberate editorial counterpoint to the new grotesk.
- Do not alter any layout, sizing, spacing, paper treatment, imagery, animation, content, colour, or section structure.

## Validation
- Compare the full page at desktop and mobile sizes.
- Confirm the new face loads, large display text remains readable, and no content overlaps or layout shifts appear.
- Confirm the paper surface and all compositions remain unchanged.
